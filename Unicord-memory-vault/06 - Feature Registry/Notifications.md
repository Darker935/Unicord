# Notifications

- `Unicord.Universal.Shared` — toasts, tiles, badges
- `Unicord.Universal.Background` — tray host
- `Unicord.Universal.Background.Tasks` — periodic / realtime tasks
- `BackgroundNotificationService` in the UI app

Uses the same user token / `TokenType.User`. Do not create a second `DiscordClient` without understanding `DiscordManager` ownership.
